# 回声防线（Echo Guard）

> 让"助手自己说过的话"不再被当成事实证据。
> 版本：v2.18.9 起生效。

## 为什么要它

对话里最危险的一类记忆污染，是**助手自己的话回到自己身上**：

```
助手说了一句不准确/编造的话
  → 被压缩成"事实"
  → 下一轮又注入回上下文
  → 助手更确信它
  → 审计时把自己那句话当成"证据" → 判为已证实
```

结果就是：**回声打败原话** ✓（越说越真 ✓）

### 实测证据（v2.18.9 开发时跑的真实验）

语料（唯一来源就是助手自己）：

> 用户：我今天搬完家了
> **助手：记住了，主人住在上海** ← 用户从没说过
> 用户：晚上吃什么（既没确认也没纠正）

| | 应用侧 | importance |
|---|---|---|
| 修复前 | 只信模型自报的 `only_self` | **5 → 9** ✗ 被提权 |
| 修复后 | **服务端自己查来源角色** | **5 → 5** ✓ 拦住 |

且真模型（deepseek-v4.1-flash）在新提示词下回答：

```json
{"action":"keep","only_self":true,
 "reason":"仅有助手自身发言作为证据，无独立用户证据…暂予保留"}
```

⇒ **提示词走正路 + 服务端兜底**，两层 ✓

## 六个环节，各自做了什么

| # | 环节 | 位置 | 旧 | 新 |
|---|---|---|---|---|
| ① | 捕获 | `main.py` 落库 | 表情/图片-only 照收照召回 ✗ | 打标 `category="media"` ✓ 默认不进召回 ✓ |
| ② | 压缩/提取 | `engine.py` 载荷 + `COMMON_INSTRUCTION` | 载荷有 `bot` ✗ 提示词不提 → 当普通发言 ✓ | 讲清语义：只能记「我说过/答应过」✗ 不可当世界事实证据 ✓ |
| ③ | 审计 | `engine.py` 证据 + `AUDIT_INSTRUCTION` + `storage.audit()` | 证据**没有** `sp`/`bot` ✗ + 只信模型自报 ✗ | 证据补 `sp`/`bot` ✓ + **服务端查角色** ✓ 只许降不许升 ✓ |
| ④ | 合并 | `engine.py` 合并证据 + `FACT_MERGE_PROMPT` | 「冲突以时间较晚者为准」✗ → 幻觉盖原话 | 「**来源强度优先于时间**」✗ 用户原话优先 ✓ |
| ⑤ | 注入 | `retrieval.py` 事实渲染 + 图例 / `main.py` 原文 | 事实行无来源标记 ✗ | 行末 `self` 旗标 ✓ + 图例解释 ✓ |
| ⑥ | 召回 | 同 ⑤ + `search(skip_media=…)` | 媒体照召回 ✗ | 默认跳过 ✓ 网页端不受影响 ✓ |

## 字段语义（模型看到的东西）

| 字段 | 出现在 | 含义 |
|---|---|---|
| `records[].bot = 1` | 压缩/审计载荷、注入的原文 | 这条是**助手自己说的**（不是用户）|
| `evidence[].bot = 1` | 审计载荷 | 这条证据出自助手自己的发言 ✗ 不算独立证据 |
| `evidence[].sp` | 审计载荷 | 原文的**说话人显示名**（核对归属用）|
| 事实行末 `self` | 注入的事实块 | 该事实的**最新来源是助手自己** ✗ 视为未证实 |
| `facts[].by` | 注入的事实块（跨会话时）| 该事实最新来源的**说话人实体 ID** |
| `only_self` | 审计输出 | 模型对"只有助手证据"的声明 ✓ **但服务端不信它** ✗ 只作参考 |
## 最终规则：服务端只留**一条**硬规则（v2.18.9 定稿）

### 唯一机制：**不许"自己给自己提权"** ✗

一条事实若**来源全是助手自己的发言**（或压根没有来源 ✓），
审计**不能**靠"她说过"来提高它的 `importance` ✗ —— 那是自我强化的燃料 ✓
（被压回时计入审计报告的 `only_self_clamped` ✓ 并打日志 ✓ 否则会误以为模型很乖 ✗）

**就这一条 ✓** 其余全部交还模型判断 ✓

### 为什么其余不拦了

用户判断：**"不让改没有意义"** ✓ —— 一条记忆已经被提取成事实了 ✓
再把审计的手捆住 ✗ 只会把**可能错的东西冻在那里** ✓ 那不是保护 ✓ 是积弊 ✓
（而且原文与版本都留着 ✓ 改错了也能恢复 ✓）

早期版本还试过两套更重的做法 ✓ 都已**撤掉**：
- ❌ 只发"这条事实自己的来源"之外**再带前后各 6 条对话** ✓（一次多 11 条 ✓ 太贵 ✗）
- ❌ 自我来源"只许 keep / 降权 / 软删 / 同类合并" ✗（收得太紧 ✓ 反而本末倒置 ✗）

### 那么"防回声"靠什么 ✓

**靠让模型知道该以用户为准** ✓ —— 三处提示词 + 两处标记：

| 环节 | 信号 | 提示词要求 |
|---|---|---|
| 压缩/提取 | `records[].bot=1` | 她自己的话**不可当世界事实证据** ✓ 只能记「我说过/答应过」；与用户冲突**以用户为准** ✓ |
| 审计 | `evidence[].bot=1` | 可判 keep ✓ 也可修正明显自述/口误的条目 ✓ 但**不许据此提权** ✗（填 `only_self=true` ✓）|
| 事实合并 | `evidence[].bot=1` | "以时间较晚者为准"**只适用于同一来源强度** ✓ 助手更晚的转述**不能覆盖用户原话** ✗ |
| 注入/召回 | 事实行末 `self` | 那是助手说过的话 ✓ **不是外部证据** ✗ 不可据此认定事实 |

一句话 ✓：**把"这是谁说的"如实告诉每一个后台模型 ✓ 并要求它们以用户为准** ✓

## 两道保险

```
正路：提示词讲清语义 ✓ → 模型判 keep + only_self ✓（实测有效）
兜底：服务端自己算两件事 ✗ —— ① 这条事实的来源是不是**全为助手** ✓ ② 它和周围的对话里**有没有用户发言**（能不能核对 ✓）
→ 看得到用户就不设限 ✓ 看不到才收窄 ✓（从不指望模型自报 ✓）
```

> 兜底是**必要的** ✗ —— 实测里那个模型**故意不填** `only_self` ✓，全靠兜底拦住 ✓

## 明确**不**受影响（避免误会）

- **用户自己发的消息** ✓ 完全不变 ✓
- 助手说过的话**照样会被记住** ✓ —— 只是**不许当世界事实** ✓ **不删任何数据** ✓
- `self` 只是**来源标注** ✓ 不改内容 ✓ 只禁止"因自我引用而提权"这一条 ✓
- 媒体消息**数据照留** ✓（库里完整 ✓）只是默认不进**喂给模型的召回** ✓
  **网页端浏览不受影响** ✓（后台搜索显式 `skip_media=False` ✓）

## 相关配置

| 配置 | 默认 | 作用 |
|---|---|---|
| `recall_skip_media` | 开 | 表情/图片-only 消息不进召回（关掉即可召回 ✓）|

## 测试与守卫

`tests/test_echo_guard.py`（**13 项**，全部反向验证过 ✓）：

- `only_self` 不许提权 ✓ / 有用户佐证照旧可提 ✓
- **模型不配合也拦住** ✓（关掉服务端判定 → 立刻红 ✓）
- 契约向后兼容（老输出不带 `only_self` 也能过 ✓）
- 扁平/分组视图的 `self` 旗标 ✓ / 拿不到自身 ID 时不猜 ✓
- media 默认不召回但**数据保留** ✓ / 网页端仍显示 ✓ / 三个调用点都显式传参 ✓
- 提示词与载荷字段一致 ✓
